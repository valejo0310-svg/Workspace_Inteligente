# My Workspace

Aplicación web desarrollada para gestionar tareas de manera sencilla y rápida.
El proyecto permite organizar actividades diarias mediante una interfaz moderna, responsiva e intuitiva.

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript

## Funcionalidades

* Agregar nuevas tareas
* Marcar tareas como completadas
* Eliminar tareas
* Filtrar tareas por estado
* Búsqueda temporal de tareas
* Modo oscuro 🌙
* Almacenamiento de datos con `localStorage` y `sessionStorage`

## Objetivo del proyecto

Practicar conceptos fundamentales de desarrollo web como manipulación del DOM, eventos, almacenamiento local y diseño responsive utilizando JavaScript puro.
